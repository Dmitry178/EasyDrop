# EasyDrop

[English](README.md) · **Русский**

**EasyDrop** – это легковесный CLI-инструмент и MCP-сервер на Go для автоматизации деплоя Docker-приложений на любые Linux-серверы (localhost, VPS, bare-metal, Raspberry Pi). 

Он предоставляет PaaS-like опыт (как в Railway или Fly.io), но на ваших собственных серверах, объединяя в себе функции оркестратора, reverse-proxy (Nginx) и автоматического выпуска SSL (Certbot).

**Статус проекта: В процессе активной разработки**
> **Примечание:** EasyDrop на данный момент является экспериментальным проектом на ранней стадии создания. Функции, описанные ниже, находятся в процессе активной реализации, поэтому возможны частые критические изменения (breaking changes). Проект пока не готов для использования в продакшене!

---

## Ключевые возможности

*   **One Core, Two Interfaces:** Единое мощное ядро деплоя, доступное как через удобный терминальный CLI, так и через MCP-сервер для AI-агентов.
*   **Zero-Config Reverse Proxy:** Автоматическая генерация конфигурации Nginx и получение SSL-сертификатов от Let's Encrypt из коробки.
*   **Remote Build (Без Registry):** Сборка Docker-образов прямо на целевом сервере – внешние Docker Registry не требуются.
*   **Zero-to-Hero Bootstrapping:** Автоматическая проверка и установка Docker Engine, Docker Compose и настройка брандмауэра на чистой VPS.
*   **AI-Native (MCP):** Полная интеграция с Cursor, Claude Code и другими AI-ассистентами для управления деплоем текстовыми командами.

## Быстрый старт

### 1. Инициализация проекта
Запустите команду в корне вашего проекта:
```bash
easydrop init
```
Инструмент автоматически проанализирует директорию и создаст файл конфигурации `easydrop.toml`.

### 2. Настройка конфигурации
Отредактируйте сгенерированный `easydrop.toml`, указав параметры вашего сервера и домен:

```toml
[app]
name = "my-awesome-api"
port = 8080             # порт, который приложение слушает ВНУТРИ контейнера
# host_port = 18080     # опционально: порт, публикуемый на хосте (по умолчанию = `port`)

[server]
host = "185.178.21.42" # Используйте "localhost" или "127.0.0.1" для локального деплоя
user = "root"
ssh_key = "~/.ssh/id_rsa"

[build]
strategy = "remote"

[driver]
type = "single"   # "single" (один контейнер), "compose" (stack-файл) или "swarm"

[nginx]
domain = "my-project.com"
ssl = true
```

### 3. Деплой
Запустите процесс развертывания одной командой:
```bash
easydrop deploy
```
EasyDrop сам подключится по SSH, проверит наличие Docker, перенесет код, соберет образ, настроит Nginx, выпустит SSL-сертификат и переключит контейнеры. По умолчанию драйвер `single` обновляет контейнер на месте; добавьте `--blue-green` для бесперебойного (Blue-Green) развёртывания – он сохраняет backup для отката. Compose- и Swarm-проекты деплоятся той же командой.

**Откат:** `easydrop rollback` возвращает предыдущую версию – остановленный контейнер-бэкап для Blue-Green, предыдущий stack-файл для Compose/Swarm.

## Использование с AI-ассистентами (MCP)

EasyDrop поддерживает **Model Context Protocol (MCP)**. Вы можете подключить его к вашему AI-клиенту (например, Cursor), добавив MCP-сервер в настройки:

*   **Тип:** `stdio`
*   **Команда:** `easydrop mcp-server` (или путь к бинарнику + аргумент `mcp-server`)

После этого вы сможете просить AI в чате:
> *"Задеплой текущий проект на сервер"*  
> *"Посмотри логи контейнера и скажи, почему падает база данных"*
